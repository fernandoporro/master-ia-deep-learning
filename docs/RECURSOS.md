# Recursos externos recomendados

Los mejores recursos **gratuitos** para complementar el curso. Al crear cada lección, enlazaremos aquí los relevantes para que puedas ampliar por tu cuenta.

> Los **datasets y archivos** van en la carpeta `recursos/` de la raíz del repo. Esta página es solo para **enlaces y referencias**.

---

## Imprescindibles (de cabecera)

- **[fast.ai — Practical Deep Learning for Coders](https://course.fast.ai/)** — enfoque práctico, de arriba a abajo. Perfecto para un dev. `[Deep Learning]`
- **[DeepLearning.AI (Andrew Ng)](https://www.deeplearning.ai/)** — las *Specializations* de ML y Deep Learning, y sobre todo los **[short courses gratis](https://www.deeplearning.ai/short-courses/)** sobre LangChain, RAG, agentes y function calling. `[ML · GenAI]`
- **[Hugging Face — Learn](https://huggingface.co/learn)** — cursos gratis: LLM/NLP Course y **Agents Course**. `[NLP · GenAI · Agentes]`
- **[Andrej Karpathy — Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html)** (YouTube) — construir redes, un GPT y el tokenizer **desde cero**. Oro puro. `[Deep Learning · Transformers]`
- **[3Blue1Brown](https://www.3blue1brown.com/topics/neural-networks)** — series de redes neuronales y de atención/GPT. La mejor **intuición visual** que existe. `[Deep Learning · Transformers]`
- **[StatQuest (Josh Starmer)](https://www.youtube.com/@statquest)** — estadística y ML explicados con una claridad brutal. `[Estadística · ML]`

## Por módulo

### Módulos 0–1 — Fundamentos y Data Science
- **[Kaggle Learn](https://www.kaggle.com/learn)** — micro-cursos de Pandas, visualización y feature engineering (+ datasets para practicar).
- **[Google ML Crash Course](https://developers.google.com/machine-learning/crash-course)**.
- StatQuest para la parte de estadística.

### Módulo 2 — Machine Learning
- **[scikit-learn — User Guide](https://scikit-learn.org/stable/user_guide.html)** — la referencia oficial.
- Andrew Ng — *Machine Learning Specialization*.
- StatQuest (árboles, random forest, boosting, PCA…).

### Módulo 3 — Deep Learning
- fast.ai + **[PyTorch — Tutorials oficiales](https://pytorch.org/tutorials/)**.
- Karpathy *Zero to Hero* (micrograd, makemore).
- 3Blue1Brown (backprop visual).

### Módulo 4 — Big Data y Cloud
- **[Apache Spark / PySpark docs](https://spark.apache.org/docs/latest/api/python/)**.
- Bases de datos vectoriales: **[pgvector](https://github.com/pgvector/pgvector)**, **[Chroma](https://docs.trychroma.com/)**.
- Tutoriales de ML del *free tier* de AWS / Google Cloud.

### Módulo 5 — NLP y Foundation Models
- **[Hugging Face — LLM/NLP Course](https://huggingface.co/learn/llm-course)**.
- Karpathy: *"Let's build GPT"* y *"Let's build the GPT Tokenizer"*.
- 3Blue1Brown sobre atención/transformers.

### Módulo 6 — Generative AI aplicada
- **[DeepLearning.AI short courses](https://www.deeplearning.ai/short-courses/)** (RAG, prompt engineering, function calling).
- **[Documentación de Claude / Anthropic](https://docs.claude.com/)** y su cookbook.
- **[Model Context Protocol (spec)](https://modelcontextprotocol.io/)**.

### Módulo 7 — Ingeniería de Agentes en Producción
- **[LangChain docs](https://python.langchain.com/)** + **[LangGraph](https://langchain-ai.github.io/langgraph/)** + [LangChain Academy](https://academy.langchain.com/).
- **[Hugging Face — Agents Course](https://huggingface.co/learn/agents-course)**.
- **[MCP — modelcontextprotocol.io](https://modelcontextprotocol.io/)** (spec + SDKs).
- DeepLearning.AI short courses de agentes (AutoGen, CrewAI, LangGraph).
